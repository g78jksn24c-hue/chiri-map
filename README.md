# 炽日 CHIRI · 轨道城市

一个轨道城市概念网站。首页采用分章节的沉浸式排版，介绍城市愿景、八个功能环和交通；八环各有独立的场景图。`pixel-city.html` 是可缩放的 2D 像素城市，九个街区与建筑地点可点击，行人和环线车辆持续移动。`pixel-map.html` 提供街道与地名搜索、地点详情和步行路线模拟。原有 `atlas.html` 保留六条高铁线路、实景鸟瞰图、动态客流仿真与单节赛博朋克高铁。猫羽雫管家提供本地站内速答并连接公开的扣子智能体；绘梨衣页面提供本地陪伴对话，并支持访问者自行配置兼容接口。

## 在线部署

仓库内容可直接通过 GitHub Pages 发布，无需构建步骤。入口文件为 `index.html`；2D 城市为 `pixel-city.html`；像素动态地图为 `pixel-map.html`；高铁沙盘为 `atlas.html`；绘梨衣页面为 `erii.html`。可选模型配置由访问者在浏览器中自行填写，仓库不含密钥。

像素城市场景、行人、时钟、街道与导航距离属于世界观模拟，不代表真实城市遥测或实际出行建议。

扣子商店页不支持直接通过 iframe 嵌入第三方网页。本站的管家速答使用前端本地知识，开放式对话会在扣子智能体页面进行；若将来取得已发布的 Chat SDK 接入配置，应由安全的服务端处理鉴权，不能把访问令牌写入公开仓库。
