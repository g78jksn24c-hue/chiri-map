# 炽日 CHIRI · 轨道城市

一个轨道城市概念网站。首页采用分章节的沉浸式排版，介绍城市愿景、八个功能环和交通；互动地图包含六条高铁线路、实景鸟瞰图、动态客流仿真与单节赛博朋克高铁。猫羽雫智能管家提供站内城市速答，并连接已公开的扣子智能体；绘梨衣页面提供本地陪伴对话，并支持访问者自行配置兼容接口。

## 在线部署

仓库内容可直接通过 GitHub Pages 发布，无需构建步骤。入口文件为 `index.html`；地图为 `atlas.html`；绘梨衣智能体为 `erii.html`。可选模型配置由访问者在浏览器中自行填写，仓库不含密钥。

扣子商店页不支持直接通过 iframe 嵌入第三方网页。本站的管家速答使用前端本地知识，开放式对话会在扣子智能体页面进行；若将来取得已发布的 Chat SDK 接入配置，应由安全的服务端处理鉴权，不能把访问令牌写入公开仓库。
